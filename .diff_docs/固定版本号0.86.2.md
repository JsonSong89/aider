# 固定版本号为 0.86.2

## 背景

官方用 `setuptools_scm` 根据 git tag 写入 `aider/_version.py`。本仓库存在 `v0.86.3.dev` 等标签时，本地会显示类似：

`0.86.3.dev13097+g7ad8f5ac8.d20260808`

AiderDesk 等会提示「新版本 0.86.2 可用」，干扰二开使用。

## 版本从哪来（改之前）

| 来源 | 作用 |
|---|---|
| `pyproject.toml` → `[tool.setuptools_scm]` | 安装/构建时按 git 生成 `aider/_version.py` |
| `aider/_version.py` | 运行时版本字符串（gitignore，可被 scm 覆盖） |
| `aider/__init__.py` | 原逻辑：先设 `safe_version`，再 import `_version`，取较高者 |

## 改动

- `aider/__init__.py`：直接固定 `__version__ = "0.86.2"`，不再 import / 抬升 scm 版本。
- `aider/_version.py`：同步写成 `0.86.2`（本地运行一致；该文件仍被 gitignore）。

## 注意

若执行 `pip install -e .` 等触发 setuptools_scm，可能再次改写 `_version.py`；因 `__init__.py` 已固定，对外仍显示 `0.86.2`。
